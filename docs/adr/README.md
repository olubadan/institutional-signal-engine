# Architecture Decision Records

Future material architecture decisions belong in this directory as immutable,
sequential records named `NNNN-short-title.md`.

Each ADR records status, context, decision, alternatives, consequences, affected
requirements, and superseding ADRs. Corrections are made by a new ADR rather than
rewriting an accepted record.

The Phase 1 reference boundaries are documented in
`../02_Reference_Architecture.md`; no implementation ADR has yet been accepted.
